# ServiceNow CSA Quick Recap Notes (Chapters 1–6)

# Chapter 1 – Introduction to ServiceNow

## ServiceNow

* Cloud-based workflow platform
* Mainly used for ITSM (Incident, Problem, Change)
* Follows SaaS model

## Important Terms

* **Instance** → Separate ServiceNow environment
* **PDI** → Personal Developer Instance
* **Admin role** → Full access
* **Application Navigator** → Search applications/modules

## Common Modules

* Incident
* Problem
* Change
* Service Catalog

## Important Points

* Uses relational database
* Accessible through browser
* Developed by ServiceNow Inc.

---

# Chapter 2 – Personal Developer Instance (PDI)

## PDI

* Free instance for learning/practice
* Created from developer.servicenow.com

## PDI Features

* Includes admin access
* Safe for testing
* Separate from production

## Important Points

* Inactive PDI → goes to sleep
* Can wake up later
* Can reset instance from Instance Actions

## Production vs PDI

| PDI          | Production       |
| ------------ | ---------------- |
| Practice     | Real business    |
| Safe testing | Live data        |
| Free         | Organization use |

# Chapter 4 – Forms & Layout

## Form

* Used to display/edit single record

## Form Layout

* Add/remove/rearrange fields

## Form Designer

* Drag and drop customization

## Field Types

### Mandatory

* Cannot leave empty
* Red asterisk (*)

### Read-only

* Visible but cannot edit

### Hidden

* Not visible on form

## Related List

* Appears at bottom of form
* Shows related records

## Views

* Different layouts for different users

## Important

Removing field from form:

* does NOT delete database column

---

# Chapter 5 – Formatters

## Formatter

* Special display section on forms

## Types of Formatters

### Activity Formatter

* Comments
* Work notes
* History

### Approval Formatter

* Approval details

### Workflow Formatter

* Workflow stages/progress

### Attachment Formatter

* Attached files

## Important

* Added using Form Layout/Form Designer

# Chapter 6 – Lists & List View

## List

* Displays multiple records

## Important Features

### Filter Condition Builder

* Filters records

### Breadcrumbs

* Shows applied filters

### Group By

* Categorizes records

### Personalize List

* Add/remove columns

### Inline Editing

* Edit directly from list

### Export

* Download as Excel/CSV

## Operators

* IS
* CONTAINS
* STARTSWITH
* ENDSWITH
