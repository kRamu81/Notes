# Introduction to ServiceNow

ServiceNow is a cloud-based platform mainly used for IT services, business processes, and other enterprise services.

ServiceNow contains modules like Incident, Problem, Change, Knowledge Management, and Service Catalog.

It mainly improves work by using Flow Designer, Integrations, Service Catalog, and Email Notifications.

It reduces manual work and saves time through automation.

Many companies use ServiceNow to reduce their work by automation.

Founder: Fred Luddy

Year: 2004

ServiceNow is mainly a low-code platform where both IT and Non-IT users can raise, view, update, assign, and resolve tickets.

So, ServiceNow is mainly a ticketing platform.

It has many products like ITSM, ITOM, HRSD, CSM, SecOps, App Engine, etc.

As a fresher, mainly focus on ITSM and ITOM.



# Architecture of ServiceNow

ServiceNow has 4 layers:

- User Interface (UI) Layer
- Application Layer
- Data Layer
- Infrastructure Layer
