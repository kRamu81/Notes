## Service Portal Overview 

### 1. What is Service Portal?
- Service Portal is a **user-friendly UI layer** for ServiceNow.
- It provides an alternative to the **standard ServiceNow UI**.
- Main focus: **End-user experience and easy access**. Pasted markdown

### 2. Main Features
- **Modular** and customizable.
- Supports different **themes and branding**.
- **Responsive** — works on different screen sizes.
- Uses **AngularJS widgets**.
- Provides a **single-page application** experience. Pasted markdown

### 3. What can users do?
- Search **Knowledge Articles**.
- Request **Catalog Items**.
- View services and information.
- Give ratings, feedback and comments.
- Filter and sort catalog items. Pasted markdown

### 4. Why Service Portal?
- Users can **find answers themselves**.
- Easy to request services.
- Easy-to-use interface.
- Helps organizations organize and present services. Pasted markdown

### 5. Single vs Multiple Portals
**Single Portal:**
- Suitable for smaller/simple organizations.
- Users can find content within **2–3 clicks**.

**Multiple Portals:**
- Useful for large organizations.
- Can create separate portals for **HR, IT, departments, companies, locations**, etc.
- Each portal can have its own URL. Pasted markdown

### 6. Service Portal vs UI Builder
| Service Portal | UI Builder |
|---|---|
| Mainly for **requesters** | Mainly for **fulfillers** |
| Uses **AngularJS widgets** | Uses modern JavaScript framework |
| Catalog requests, information | Fulfiller/work experience |
| Established portal framework | Newer/upcoming approach |
