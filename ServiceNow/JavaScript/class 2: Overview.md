### What is Programming?

- Programming means giving instructions to the computer to perform a certain task.
- Programming is used by developers to build applications.

---

### What is JavaScript?

- JavaScript is a **High-Level Programming Language**, **Object-Oriented**, and **Multi-Paradigm** language.

### 1. High-Level Programming

- We don't need to know the implementation details.
- We only focus on concepts like variables, arrays, loops, functions, etc.
- This is called **Abstraction**.

### 2. Object-Oriented Programming (OOP)

- JavaScript supports Object-Oriented Programming.
- We can create **classes** and **objects**.
- Inside a class, we create **properties** and **methods**.

#### Main OOP Concepts

- **Abstraction** – Hides the implementation details.
- **Encapsulation** – Properties and methods are kept together inside a class.
- **Inheritance** – A child class inherits properties and methods from the parent class.
- **Polymorphism** – Performing a single action in different forms.

### 3. Multi-Paradigm

- Multi-paradigm means we can solve a problem in different programming styles.

Types:
- Imperative Programming
- Declarative Programming

Examples:
- JavaScript
- Python
- Ruby

### Evolution of JavaScript

- **1993** – Mosaic was the first popular web browser.
- **1994** – Netscape Corporation was founded by the lead developer of Mosaic.
- **1995** – Brendan Eich created JavaScript and first named it **Mocha**.
- **1996** – Mocha was renamed to **LiveScript**.
- **1996** – Because Java was very popular, LiveScript was renamed to **JavaScript** to attract developers.
- **1996** – Microsoft launched **Internet Explorer (IE)**.
- **1996** – **ECMA** was formed to standardize JavaScript.
- **1997** – **ECMAScript 1 (ES1)** was released.
- **2009** – **ES5** was released (one of the biggest updates).
- **2015** – **ES6 (ECMAScript 2015)** was released (modern JavaScript and one of the biggest updates).
- **After 2015** – A new ECMAScript version is released almost every year.
- **ServiceNow Tokyo** supports many modern JavaScript (ES12/ES2021) features.
